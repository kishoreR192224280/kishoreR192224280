## Featured Projects

### Sigma Graphics

Production website and API for a graphics studio: services, portfolio, contact, and PayPal checkout.

- Next.js and React frontend with a FastAPI REST API
- PostgreSQL with SQLAlchemy and Alembic (migrated from MySQL)
- Payments, invoicing, and transactional email
- Deployed on a Linux VPS behind Nginx, with a Render blueprint for the same stack

**Tech:** Next.js · TypeScript · React · Tailwind CSS · FastAPI · PostgreSQL · SQLAlchemy · Nginx · Linux

[Live site](https://sigmagraphics.us)

### Real-Time Quiz Platform

Live quiz product for conference and classroom sessions — admin control, student join codes, leaderboard, and a big-screen display.

- Socket.IO server for session state, reconnect handling, and leaderboard pushes
- PHP/Apache API with PostgreSQL
- Admin dashboard, session control, reports, and audience join flow

**Tech:** React · TypeScript · Vite · Tailwind CSS · Node.js · Socket.IO · PHP · Apache · PostgreSQL · Docker · Vercel

[Frontend](https://github.com/kishoreR192224280/EUROPE-CONFERENCE) · [Backend](https://github.com/kishoreR192224280/website-backend) · [Live demo](https://europe-conference.vercel.app)

### PancreaScan

Web client for pancreatic scan review with on-device inference, 3D visualization, and local PDF reports.

- ONNX Runtime in the browser for on-device analysis
- Three.js scan visualization
- Auth, dashboard, patient history, analytics, and PWA support

**Tech:** React · TypeScript · Vite · Three.js · ONNX Runtime · GitHub Pages

[GitHub](https://github.com/kishoreR192224280/PancreaScan-Web) · [Live demo](https://kishoreR192224280.github.io/PancreaScan-Web)

### MicroLearn

Microlearning platform with learning paths, card-based lessons, quizzes, and progress tracking.

- React and Vite client with an Express.js API
- PostgreSQL via Drizzle ORM
- REST endpoints for paths, cards, quizzes, and progress

**Tech:** React · TypeScript · Vite · Tailwind CSS · Node.js · Express.js · PostgreSQL

[GitHub](https://github.com/kishoreR192224280/MIcroLearn)
